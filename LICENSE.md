Software. Rendered previews are a visualization aid and may differ from the
actual representation in TIA Portal. The Licensor does not review, validate,
approve or endorse Your Content and assumes **no liability** for it.

**14.3 Going online to a controller.** When you go online — yourself, another
person using your installation, or an AI Assistant through the Software's
language model tools or the built-in MCP server — the Software connects from
your computer to the web
server of a physical SIMATIC S7 CPU and can read and **write variable values on
a running controller**. Every such write can immediately change the behaviour of
the controlled machine or process. **You alone are responsible for every effect
of every Online Session and of every value read or written through it**,
including production downtime, off-specification or damaged product, damaged
equipment and any consequential loss — regardless of whether the access was
initiated by you or by an AI Assistant acting on your behalf. In particular, you
are responsible for:

1. deciding which controllers the Software may connect to, from which
   workstations, and who may trigger that connection;
2. the configuration of the PLC web server, its users and their access levels
   in TIA User Management — the Software only uses the access rights of the
   web-server user whose credentials you provide and never bypasses them;
3. checking the current state of the machine or process before every write;
4. ending Online Sessions when they are no longer needed.

The Licensor is not liable for any consequence of an online read or write.

**14.4 AI-assisted output.** The Software exposes language model tools and a
built-in MCP server that allow AI Assistants (such as GitHub Copilot or other
MCP clients) to list your Online Sessions, to
read online values and trend recordings of your PLC and to write variable
values to it. Output produced by such assistants is **generated automatically,
may be incorrect, incomplete or unsafe, and is not verified by the Licensor**.
The AI models are operated by third parties under their own terms; the Licensor
is not a party to that processing and is not liable for its results. Every write

decision, and you bear full responsibility for AI-initiated writes that then
reach the controller without an individual confirmation. You are responsible for
reviewing every AI-initiated read or write before it reaches a controller.

**14.5 Verification is on you.** **You remain solely responsible** for
reviewing, testing, simulating, commissioning and validating every value before
it is written to a machine or process — whether the value comes from you, from a

**14.9 Built-in MCP server and local automation.** The Software contains a
Model Context Protocol (MCP) server, **enabled by default**, that exposes the
PLC online tools (listing Online Sessions, reading and writing variable
values, trend recordings) to local programs. It listens on `127.0.0.1` only
and requires a per-session Bearer token. Any program that you connect to it,
or that can read the token file `.tia/mcp-viewer.json`, can read online data
from your controllers and request writes. Every write initiated through the
MCP server is confirmed by you in a dialog, unless you enable
`tiaViewer.lmTools.autoConfirmPlcWrites`. You therefore:

1. decide which MCP clients, agents and scripts you connect, and assess their
   trustworthiness yourself;
2. protect your user account and workspace so that untrusted software cannot
   read the token file;
3. switch the MCP server off (`tiaViewer.mcp.enabled = false`) if you do not
   use it.

including the local-only binding, the token check and the per-write
confirmation safeguard. The Licensor is not liable for actions performed by
clients you connected or for damage caused by malicious or compromised
third-party software on your computer, including data leakage or unauthorised
writes to your controllers.
